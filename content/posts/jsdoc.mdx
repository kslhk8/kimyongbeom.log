##### @type    
변수를 만들 때 타입을 적을 수 있는 키워드   
```
/** @type {string} */
let name = 'Example'
```
   
##### @param, @returns   
@param   
함수의 매개변수를 설명하는 키워드     
{ } 안에는 매개변수의 타입을 넣는다.   
   
@returns    
함수의 리턴값에 대한 설명   
```
/**
* 두 수의 합을 구하는 함수입니다.
* @param {number} a - first item
* @param {number} b - second item
* @returns {number} 두 인자를 합친 결과값을 리턴합니다.
const add = (a, b) => a + b;
```
